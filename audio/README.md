# Narration audio

Put one file per story page and language here, named:

```
{bookid}-p{1-5}-{en|es}.m4a
```

Book ids: `eagle`, `grail`, `viking1`, `opportunity`.
Example: `eagle-p3-es.m4a` is the Spanish narration of page 3 of the Apollo 11 book.

If a file is missing, the site hides that page's play button.
